# SubtitleAutoSync — مزامنة الترجمة تلقائياً

العربية · **[English](README.md)**

أداة تضبط توقيت ملف الترجمة تلقائياً، وتشتغل مع **أي مشغل**.
تعطيها الفيديو وملف ترجمة خارجي (`.srt` أو `.vtt` أو `.ass` أو `.ssa`) توقيته غلط، فتقارنه بتوقيت ترجمة **مدمجة أصلاً داخل الفيديو** وتطلع لك ملفاً مضبوطاً.

- تصلح **التأخير أو التقديم الثابت** (الترجمة متقدمة أو متأخرة 3 ثوانٍ طول الفيلم)
- تصلح **فرق معدل الإطارات** (23.976 / 24 / 25 إطاراً: الترجمة تبتعد عن الصوت شيئاً فشيئاً)
- **ما تخرب شيئاً أبداً**: إذا ما كانت متأكدة تترك الملف كما هو
- تغيّر **التوقيت فقط**: النص والتنسيق والترميز (UTF-8، وWindows-1256 العربي، وUTF-16…) يبقى كما هو حرفياً، فما يصير عندك حروف عربية مكسّرة
- تقرأ **فهرس** الفيديو فقط وليس الفيديو نفسه، فملف MKV بحجم 50 جيجا ينتهي في أجزاء من الثانية

```
الفيديو (فيه ترجمة مدمجة)       ─┐
                                 ├─►  مقارنة أوقات البداية  ─►  الجديد = القديم × السرعة + الإزاحة  ─►  ترجمة مضبوطة
ملف الترجمة الخارجي (غير مضبوط)  ─┘                              (فقط إذا كانت متأكدة)
```

> **مهم:** لازم يكون في الفيديو ترجمة مدمجة واحدة على الأقل (بأي لغة، مثلاً إنجليزي)، وهذه تكون "ورقة الإجابة". اللغة ما تفرق لأن المقارنة على التوقيت فقط. ما فيه ترجمة مدمجة؟ تقدر تستخدم أي ملف ترجمة توقيته صحيح بدلاً منها (الشرح تحت).

## 1. أبي أصلح ترجمة فقط (لأي مشغل)

تنفع مع VLC وMPC-HC وPotPlayer وIINA وKodi وInfuse وPlex وJellyfin والشاشات الذكية، يعني أي مشغل يقبل ملف ترجمة.

**الخطوة 1: ثبّت Python 3** (مجاني): <https://www.python.org/downloads/>
في ويندوز فعّل خيار **"Add Python to PATH"** أثناء التثبيت.
إذا الفيديو **MP4** أو أي صيغة غير MKV ثبّت كذلك **FFmpeg** من <https://ffmpeg.org/download.html>. ملفات MKV ما تحتاج شيئاً إضافياً.

**الخطوة 2: نزّل الملف** [`python/subautosync.py`](python/subautosync.py) (ملف واحد، ما يحتاج أي مكتبات).

**الخطوة 3: شغّله** من الطرفية (في ويندوز: Command Prompt أو PowerShell) في نفس المجلد:

```bash
python3 subautosync.py "Movie.mkv" "Movie.ar.srt" --lang ar
```

(في ويندوز اكتب `python` بدل `python3`.)

النتيجة:

```
✅ تمت المزامنة: تم تقديم الترجمة 6.5 ثانية (تطابق 100%)
المرجع: embedded track #3 eng S_TEXT/UTF8 (1243 cues)
الملف: Movie.ar.synced.srt
```

**الخطوة 4: افتح الملف `Movie.ar.synced.srt` في مشغلك** مثل أي ترجمة.
نصيحة: إذا سمّيته بنفس اسم الفيديو بالضبط (`Movie.srt` أو `Movie.ar.srt`) وحطيته جنب الفيديو، أغلب المشغلات (VLC وmpv وKodi وPlex وJellyfin وInfuse) تحمّله تلقائياً.

### خيارات مفيدة

| الخيار | وش يسوي |
|---|---|
| `-o out.srt` | تختار اسم الملف الناتج |
| `--in-place` | يكتب فوق الملف الأصلي (ويحتفظ بنسخة `.bak`) |
| `--lang ar` | الرسائل بالعربي |
| `--track 3` | تختار أي ترجمة مدمجة تكون المرجع |
| `--min-match 0.6` | يصير أشد (الافتراضي 0.45 يعني لازم 45% من الأسطر تتطابق) |
| `--json` | نتيجة بصيغة JSON (للسكربتات والتطبيقات) |

### الفيديو ما فيه ترجمة مدمجة؟

استخدم أي ترجمة تعرف أن توقيتها صحيح لنفس الفيديو (مثلاً الإنجليزية) كمرجع:

```bash
python3 subautosync.py "Movie.en.srt" "Movie.ar.srt" --lang ar
```

### معنى الرسائل

| الرسالة | المعنى |
|---|---|
| ✅ تمت المزامنة | انضبطت وانحفظت |
| ✅ متزامنة أصلاً | كانت مضبوطة، ما يحتاج شيء |
| ⚠️ التطابق 31% فقط | غالباً الترجمة لنسخة ثانية من الفيلم (إصدار مختلف) |
| ⚠️ نسخة مونتاج مختلفة | الترجمة لنسخة فيها مشاهد زيادة أو ناقصة (مثل Director's Cut). ما تنصلح بإزاحة وحدة بأمان، فما تغيّر شيء |
| ⚠️ لا توجد ترجمة مدمجة | الفيديو ما فيه ترجمة تنفع مرجعاً. استخدم ملف ترجمة ثاني كمرجع |

## 2. مشغل mpv: مزامنة بزر واحد

1. انسخ المجلد [`players/mpv/subautosync/`](players/mpv/subautosync) إلى مجلد `scripts` الخاص بـ mpv:
   - ويندوز: `%APPDATA%\mpv\scripts\subautosync\`
   - ماك ولينكس: `~/.config/mpv/scripts/subautosync/`
2. حط الملف `python/subautosync.py` **داخل نفس المجلد** (جنب `main.lua`).
3. شغّل الفيديو، حمّل الترجمة، واضغط **Ctrl+y**. الترجمة المضبوطة تنحمّل وتنختار تلقائياً.

إعدادات اختيارية في الملف `script-opts/subautosync.conf`:

```ini
lang=ar        # الرسائل بالعربي
auto=yes       # يزامن تلقائياً كل ما اخترت ترجمة خارجية
python=python  # في ويندوز إذا ما لقى python3
```

## 3. للمطورين: كيف تضيفها لمشغلك

فيه محرّكان جاهزان **نتائجهما متطابقة** (الاثنين مختبرين على نفس الـ 480+ حالة مرجعية):

| أنت تبني… | استخدم |
|---|---|
| تطبيق iOS أو tvOS أو macOS أو visionOS (Swift) | **حزمة Swift** (جذر هذا المستودع) |
| أي شيء ثاني (Python، إضافة Kodi، سيرفر، برنامج سطح مكتب)، أو تشغيله كعملية جانبية | **`python/subautosync.py`** (`import subautosync` أو استدعاء الأداة مع `--json`) |
| مشغل Kotlin أو Java أو C# أو JS أو C++ | انقل `python/subautosync.py` للغتك (تقريباً 1000 سطر، بدون مكتبات) أو شغّله كعملية. الاختبارات في `python/tests` وملفات `Tests/.../Fixtures` تقول لك إذا نقلك مطابق 100% |

### الطريقة (نفسها لكل مشغل)

مهما كانت المنصة، الربط دائماً 4 خطوات:

**1. جيب المرجع: أوقات بداية كل سطر (بالملي ثانية) من ترجمة مدمجة.**

| مشغلك مبني على | كيف تجيب الأوقات |
|---|---|
| **FFmpeg** (أغلب المشغلات الخاصة، KSPlayer، mpv، VLC داخلياً، IINA) | بعد `avformat_find_stream_info` نفّذ `avformat_seek_file(fmt,-1,INT64_MIN,0,INT64_MAX,0)` مرة وحدة **قبل بدء التشغيل** (هذا يخلي FFmpeg يقرأ فهرس Cues في MKV)، بعدها اقرأ `avformat_index_get_entry()` لمسار الترجمة. في MP4 الفهرس جاهز من أول ما ينفتح الملف، بس تجاهل عينات `mov_text` اللي حجمها 2 بايت أو أقل. كود جاهز: [`Integration/FFmpegSubtitleIndex.swift`](Integration/FFmpegSubtitleIndex.swift) |
| **AVPlayer أو ExoPlayer أو `<video>` في الويب** (ما عندك وصول للـ demuxer) | اقرأ فهرس MKV بنفسك بطلبات HTTP Range: `MatroskaCues` + `HTTPRangeSource` في Swift، أو `MatroskaCues` في ملف Python. عادةً 2 إلى 3 طلبات وأقل من 2 ميجا. أرسل نفس الـ headers اللي تشغّل فيها (توكن Emby أو Jellyfin أو Plex) |
| **ملفات محلية، أي مشغل** | `subautosync.load_reference(path)` في Python: يدعم MKV مباشرة، والباقي عن طريق `ffprobe` |
| **ما فيه ترجمة مدمجة** | استخدم ملف ترجمة ثاني توقيته صحيح كمرجع |

**2. خذ بايتات ملف الترجمة الخارجي كما هي** (لا تفك ترميزها ولا تعيد ترميزها).

**3. طابق وقرّر:**

```python
import subautosync as S
ref, _ = S.load_reference("movie.mkv")              # أو قائمتك الخاصة من أوقات البداية بالملي ثانية
outcome = S.synchronize(sub_bytes, "movie.ar.srt", ref)
if outcome.status == "synced":
    fixed_bytes = outcome.data                       # نفس الترميز، التوقيت فقط تغيّر
print(S.describe(outcome, "ar"))                     # رسالة للمستخدم (ar أو en)
```

**4. طبّق النتيجة** (اختر وحدة):
- **استبدل الترجمة** بالبايتات المضبوطة (تنفع مع أي محرك عرض، حتى libass)، أو
- **لا تلمس الملف** وحوّل الساعة بدلاً منه: `وقت_الترجمة = (وقت_التشغيل − offset_ms) ÷ scale`.

### قواعد تخلي التجربة ممتازة

- **لا تخلي التشغيل ينتظر أبداً.** اعرض الترجمة الأصلية فوراً، زامن في الخلفية، وبدّلها لما تخلص.
- **آخر اختيار هو المعتمد.** إذا غيّر المستخدم الترجمة أثناء المزامنة، تجاهل النتيجة القديمة.
- بعد التطبيق **صفّر تأخير الترجمة اليدوي** (وأي تعديل يدوي بعدها ينضاف فوقه).
- إذا المستخدم اختار الترجمة بنفسه: اعرض له النتيجة دائماً. إذا انختارت تلقائياً: اعرض الرسالة فقط إذا فعلاً انضبطت.
- حط زر **"مزامنة الترجمة الحالية"** في قائمة الترجمة.
- أوقفها في البث المباشر وIPTV وHLS وDASH (ما فيه فهرس ينقرأ، وIPTV غالباً يسمح باتصال واحد بس).
- خزّن النتائج بمفتاح *بصمة الترجمة + معرّف ثابت للفيديو* (مو الرابط، لأن الروابط فيها توكن مؤقت).

### بداية سريعة في Swift

أضف الحزمة في Xcode: **File → Add Package Dependencies…** ← `https://github.com/6ahd/SubtitleAutoSync`

```swift
import SubtitleAutoSync

// مشغلك يطبّق 4 دوال فقط:
// currentExternalSubtitleID(slot:), replaceExternalSubtitle(slot:id:data:fileName:),
// resetManualSubtitleDelay(slot:), showToast(_:)
let coordinator = AutoSyncCoordinator(player: self, language: .ar)   // .en أو .ar أو .zh

// 1. لما ينفتح الفيديو (الخيط الرئيسي)
coordinator.mediaDidOpen(MediaSource(url: streamURL, headers: playbackHeaders,
                                     cacheKey: "emby:\(itemId)", isLive: isLive),
                         mode: .ffmpegIndex)        // .httpRange إذا ما عندك AVFormatContext

// 2. خيط الـ demuxer، بعد avformat_find_stream_info وقبل التشغيل (لمشغلات FFmpeg فقط)
FFmpegSubtitleIndex.loadIndex(fmt)
let starts = FFmpegSubtitleIndex.reference(fmt)?.startsMs
Task { @MainActor in coordinator.setFFmpegReference(starts) }

// 3. لما تبدأ الترجمة الخارجية تظهر
coordinator.subtitleDidLoad(slot: 0, id: sub.id, data: sub.data, fileName: sub.fileName,
                            userInitiated: userPicked)

// 4. زر "مزامنة الترجمة الحالية"
coordinator.syncNow(slot: 0, id: sub.id, data: sub.data, fileName: sub.fileName)
```

المحرك فقط بدون المنسّق:

```swift
let engine = SubtitleAutoSyncEngine()
let outcome = await engine.synchronize(subtitle: srtData, fileName: "movie.ar.srt",
                                       reference: ReferenceTimeline(starts: startsMs), cacheKey: "emby:123")
if case .synced(let s) = outcome {
    replaceCurrentSubtitle(with: s.data)
    showToast(s.alignment.summary(.ar))   // "تم تقديم الترجمة 6.5 ثانية (تطابق 100%)"
}
```

الملف `Integration/FFmpegSubtitleIndex.swift` **مو** جزء من الحزمة (لأنه يعتمد على FFmpeg): انسخه لمشروعك وغيّر `import CFFmpeg` لاسم وحدة FFmpeg عندك.

المتطلبات: iOS 15 / tvOS 15 / macOS 12 / visionOS 1، وSwift 5.9 أو أحدث، بدون أي مكتبات خارجية.

## 4. كيف تشتغل

فيه نوعين فقط من عدم التزامن ينصلحون تلقائياً بأمان، والاثنين خط مستقيم: **الوقت الجديد = الوقت القديم × السرعة + الإزاحة**.

1. **المرجع**: وقت بداية كل سطر في الترجمة المدمجة (من فهرس الملف، بدون فك ترميز الفيديو).
2. **التصويت**: لكل سرعة من 7 سرعات (1، 25/23.976، 23.976/25، 25/24، 24/25، 24/23.976، 23.976/24)، كل سطر يصوّت للفرق "المرجع − الترجمة" في خانات كل خانة 100 ملي ثانية (±300 ثانية). مع السرعة الصحيحة تقريباً كل الأسطر تصوّت لنفس الخانة فتطلع قمّة واضحة. أعلى القمم تصير مرشّحة.
3. **التحسين**: كل مرشّح يتطابق كل سطر فيه مع أقرب سطر مرجعي (350 ملي ثانية أو أقل)، يتصحح بالوسيط مرتين، بعدين ملاءمة بالمربعات الصغرى للسرعة والإزاحة.
4. **القرار**: يطبّق فقط إذا 45% من الأسطر أو أكثر تطابقت، والنتيجة أحسن من أفضل حل *مختلف* بـ 20 نقطة على الأقل، وتطابق 20 سطراً على الأقل. إذا الحركة أقل من 250 ملي ثانية تعتبر متزامنة أصلاً.
5. **فحص نسخة المونتاج**: بداية الفيلم ووسطه ونهايته (كل ثلث) ينفحص لوحده. إذا ثلث منهم يفضّل إزاحة ثانية، فالترجمة لنسخة مختلفة، وما يتغيّر شيء.
6. **إعادة الكتابة**: التوقيتات فقط، بنفس الشكل الأصلي (فاصلة أو نقطة، الساعات، أجزاء الثانية في ASS) ونفس الترميز.

فيلم مدته ساعتين فيه 1500 سطر يتطابق في حوالي 10 إلى 15 ملي ثانية (Swift، نسخة release).

ملاحظات التصميم الكاملة (بالصيني، المستند الأصلي) في [`docs/design-notes.zh.md`](docs/design-notes.zh.md)، وفيها كمان خطة المزامنة بالصوت للفيديوهات اللي ما فيها أي ترجمة مدمجة.

## 5. محتويات المستودع

| المسار | وش فيه |
|---|---|
| `python/subautosync.py` | محرك Python في ملف واحد + أداة سطر أوامر (أي نظام، أي مشغل) |
| `python/tests/` | اختبارات تطابق نسخة Python |
| `players/mpv/` | سكربت mpv: Ctrl+y للمزامنة |
| `Sources/SubtitleAutoSync/` | حزمة Swift (المحرك، قارئ فهرس MKV، HTTP Range، المنسّق، الرسائل بالعربي والإنجليزي والصيني) |
| `Integration/FFmpegSubtitleIndex.swift` | قراءة أوقات المرجع مباشرة من `AVFormatContext` في FFmpeg |
| `Tests/` | اختبارات Swift + ملفات اختبار مشتركة (480+ حالة مرجعية، وملفات MKV وMP4 حقيقية) |
| `docs/design-notes.zh.md` | مستند التصميم الأصلي |
